GetApi is a Dutch platform that offers a collection of powerful APIs for web scraping, email validation, geolocation and more. Users can discover, test and integrate these APIs through a unified interface, with a free tier to start quickly. The service focuses on providing reliable data extraction and validation tools for developers and businesses across various use cases.

**Areas:** Company · API · Dutch · WebScraping · DataValidation

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for getapi-nl: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
